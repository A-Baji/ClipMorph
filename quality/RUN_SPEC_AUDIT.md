# Spec Audit Protocol

> Generated by Quality Playbook v1.5.6 — Andrew Stellman
> Date: 2026-09-24 · Project: short-form-content-converter

Three independent reviewers compare `quality/REQUIREMENTS.md`, README, `docs/CLI_WEB_PARITY.md`, `docs/PACKAGE_MATRIX.md`, and the cited source locations. Each reviewer must issue per-requirement SATISFIED, VIOLATED, or UNCLEAR verdicts. Triage minority findings by rereading the source and writing an executable assertion. Confirmed findings must be copied to `quality/BUGS.md` and receive regression tests.

Primary lenses are lifecycle/cancellation, CLI-web parity, config precedence, concurrent platform state, and policy transformation flow. No formal `reference_docs/` records exist; reviewers must label requirements as source-derived.
