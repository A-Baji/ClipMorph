# Code Review Protocol

> Generated by Quality Playbook v1.5.6 — Andrew Stellman
> Date: 2026-09-24 · Project: short-form-content-converter

Run three passes against the current HEAD using `python -m unittest` conventions and exact file/line citations.

## Pass 1 - Structural

Inspect input validation, resource lifecycle, state/concurrency, unit/encoding correctness, and enumeration completeness. Read function bodies. Report QUESTION when intent is unclear.

## Pass 2 - Requirements

Verify REQ-001 through REQ-006 individually. Each verdict must cite a code location and a concrete execution or source assertion. Confirm every cancellation return, CLI/web metadata path, config default, platform aggregation branch, policy transformation consumer, and resume check.

## Pass 3 - Consistency

Compare CLI versus web workflow, preflight versus policy, platform result order versus retry, and manifest status versus step state. Confirm no requirement is satisfied in one entry point and bypassed in another.

For each confirmed bug, add a regression test patch under `quality/patches/` and record the exact reproduction command.
