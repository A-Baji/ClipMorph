# Integration Test Protocol

> Generated by Quality Playbook v1.5.6 — Andrew Stellman
> Date: 2026-09-24 · Project: short-form-content-converter

Run from the repository root with temporary data directories and no live credentials. Existing selectors are standard-library unittest, so use the narrowest module selector available. Map groups to UC-01 through UC-05; build and structure checks are infrastructure groups. Verify manifests, artifact paths, status, and per-platform results after each run. Live provider calls are excluded unless a supervised integration environment is explicitly provided.

| Group | Use cases | Command | Pass criteria |
|---|---|---|---|
| Lifecycle | UC-01, UC-05 | `python -m unittest tests.test_web tests.test_cli -v` | cancellation/resume responses and manifest state agree |
| Upload state | UC-04 | `python -m unittest tests.test_cli -v` | partial results remain per platform |
| Parity | UC-02, UC-03 | `python -m unittest tests.test_web tests.test_cli -v` | equivalent normalized config and validation |
| Infrastructure | none | `python scripts/check_structure.py` | structure policy passes |

Record results in `quality/results/integration-results.json` with groups, summary, and UC coverage.
