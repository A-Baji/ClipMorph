## Findings disposition

### BUG-001 - Empty upload list skips all web uploads

- Source: Pass 2 and Pass 3
- File: `clipmorph/workflow.py:15-18`
- Severity: HIGH (silent user-facing data-flow omission; no upload occurs while the job can complete)
- Expected: an empty `upload_to` means all supported platforms, per `clipmorph/cli.py:147-151` and `__main__.py:16-29`.
- Actual: `configuration.get("upload_to", defaults)` returns `[]` when the key exists with an empty list, and the workflow constructs `UploadPipeline()` with no enabled platforms.
- Reproduction: `python -m unittest quality.test_regression -v` with the expected-failure guard removed; current behavior fails the assertion that all four platform flags are enabled.
- Regression test: `quality/patches/BUG-001-regression-test.patch`
- Proposed fix: `quality/patches/BUG-001-fix.patch`
