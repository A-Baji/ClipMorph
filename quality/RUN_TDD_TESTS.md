# TDD Verification Protocol

> Generated by Quality Playbook v1.5.6 — Andrew Stellman
> Date: 2026-09-24 · Project: short-form-content-converter

For every confirmed bug, apply the regression-test patch in a disposable worktree. Run the test against unpatched code and record a `RED` log, then apply the fix patch if present and record a `GREEN` log. If a fix is not supplied, retain the regression test as confirmed-open and document why. Never apply patches to the working source tree during the audit.
