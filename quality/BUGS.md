### BUG-001

**Title:** Empty `upload_to` skips all uploads in the shared workflow.

**Source:** Code Review and Spec Audit

**File:** `clipmorph/workflow.py:15-18`

**Severity:** HIGH

**Requirement:** REQ-002

**Disposition:** code-fix

**Problem:** The documented configuration template uses `upload_to: []` to mean all platforms, and the CLI implements that behavior. The shared workflow uses the empty list unchanged, so dashboard jobs construct an upload pipeline with no enabled platforms and can complete without uploading.

**Expected:** Empty selection enables YouTube, Instagram, TikTok, and Twitter.

**Actual:** Empty selection enables zero platforms in `execute_job`.

**Evidence:** `clipmorph/cli.py:147-151`, `clipmorph/__main__.py:16-29`, and `clipmorph/workflow.py:15-18`. Red command: `python -m unittest quality.test_regression.RegressionTests.test_bug_001_empty_upload_list_means_all_platforms -v`; result: exit 1 with an assertion that `{}` did not equal the four expected platform flags. Green command in disposable worktree after applying `quality/patches/BUG-001-fix.patch`; result: exit 0.

**Regression test:** `quality/patches/BUG-001-regression-test.patch`

**Fix patch:** `quality/patches/BUG-001-fix.patch`

**Acceptance:** Add the same empty-list normalization used by the CLI before constructing the shared upload pipeline; the regression test passes.
