# Quality Constitution

> Generated by Quality Playbook v1.5.6 — Andrew Stellman
> Date: 2026-09-24 · Project: short-form-content-converter

Quality means a creator can trust that a job's media, credentials, lifecycle state, and platform results remain accurate across cancellation, restart, partial failure, and CLI/web entry points.

## Coverage Targets

| Area | Target | Rationale |
|---|---:|---|
| Job and workflow state | 100% lifecycle transitions | Cancellation and partial failure can otherwise strand jobs. |
| CLI/config/preflight | 90% boundary cases | Preflight is the safety boundary and precedence is user-visible. |
| Upload orchestration/policy | 90% result and transformation cases | Concurrent platform outcomes and limits must remain distinct. |
| Web/service parity | 80% route-to-workflow cases | Dashboard promises the same job model as CLI. |

## Fitness-to-Purpose Scenarios

1. Cancel after preflight: manifest is not left active (`workflow.py:47-49`).
2. Cancel during conversion: partial artifact and status are explicit.
3. CLI/web same manifest: effective config and policy decisions match (`__main__.py`, `workflow.py`).
4. YAML false/list override: explicit config is not lost (`cli.py:106-121`).
5. Out-of-order platform results: one failure does not erase another success (`job.py:127-136`).
6. Retry one failed platform: previously successful platforms remain complete.
7. Caption limit: transformed caption is the value sent (`policy.py:104-110`).
8. Resume changed source: path/hash mismatch is rejected (`__main__.py:105-112`).

## Coverage Theater Prevention

Do not count import-only tests, mock assertions that merely repeat configured return values, or route tests that never inspect persisted manifests as lifecycle coverage. Assertions must verify observable status, source identity, policy output, and per-platform result state.

## AI Session Quality Discipline

Read the relevant function bodies, cite exact paths, reproduce each confirmed bug, and preserve the existing unittest and temporary-directory conventions. Never use live credentials or uploads.

## Human Gate

Confirm platform policy limits against current provider contracts before changing `CAPABILITY_MATRIX`; external limits can change independently of this repository.
